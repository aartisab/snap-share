# snap-share

How to Run Implementation Prototypes:
1.  Go to the app/prototypes folder and choose the Prototype you want to view.
2.  app/app/(tabs) and open "index.tsx"
3.  Replace line 2 with import [prototype_name] from '../../prototypes/[prototype_name]';
4.  Replace line 5 with return <[prototype function from prototype file] />;
5.  In terminal, go into the app folder (cd app).
6.  Run the following command:  npx expo start
7.  Select the letter of the way you want to view the prototype.
